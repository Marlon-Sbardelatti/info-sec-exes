## Funcionamento 
    A implementação do arquivo main.py simula a interação entre dois usuários (Marlon e Sofia)

## Outputs
    Os outputs de cada questão se encontram em: 

    1. marlon/01 ... 04/
    2. sofia/01 ... 04/

## Keys
    As chaves privadas e públicas de cada usuário são armazenadas em:

    1. marlon/keys/
    2. sofia/keys/
